# STM Simulator

VASP PARCHG 桌面后处理。深色控制面板，恒高切片、恒流等值面、上下表面、搜索范围、可选高斯平滑、鼠标读数与 PNG/CSV/NPZ 导出。

## 运行

```sh
python -m pip install -r requirements.txt
python run.py
```

Windows 双击 `start.vbs` 无控制台启动，失败时查看 `startup-error.log`。

Python 3.10+，需要 PyQt6、NumPy、SciPy、PyQtGraph、PyOpenGL。点击“打开文件”载入 PARCHG，设置参数后运行模拟。

## 模型

Tersoff–Hamann 近似，以所选偏压能窗的部分密度作为电流代理。偏压能窗应在 VASP 的 EINT 中指定。程序保留原始 PARCHG 数值，阈值不标定为 pA/nA。读取第一数据块，即共线自旋计算的总密度。文件不保存原始波函数相位。

恒高采用相邻 z 平面线性插值。恒流按选定表面从真空向原子层搜索，采用首次向上跨越阈值的交点，再线性插值。限定真空模式只搜索最外层原子之外的真空。没有交点显示为 NaN/洋红色。阈值过低/高、模型跨周期边界时，请检查或显式指定搜索范围。仅支持 a,b 位于 xy 且正 c 轴沿 z 的晶胞，支持面内非正交网格。默认关闭平滑，sigma 单位为网格间距。

## Qt UI 与 p4vasp 移植

界面改为 PyQt6，移除底部日志，采用参考控制面板的 8px 面板圆角、4px 卡片圆角与中性深灰配色。

默认恒流引擎是 p4vasp 线性移植，保留最低平均密度层起点、周期边界与首次达到阈值规则。无交点用 NaN，未移植三次模式。完整出处与许可证见 THIRD_PARTY.md。限定真空引擎仍可选择。

项目记忆入口见 `.memory/AGENTS.md`，界面约定见 `.memory/designs/ui.md`。

## 双视图与参数

左侧二维图和右侧可旋转三维图由同一次模拟同步更新。三维图可勾选显示原子。恒流模式调整“目标信号 / 原始密度”，恒高模式调整“距外层原子 / Å”，拖动滑条或修改对应数值后自动更新两图，也可点击“运行模拟”。恒高三维图使用实际截面高度，密度由颜色表示。三维绘制最多采用160×160采样点，计算和导出保持原始分辨率。

导入时显示密度网格读取进度。原子直接使用文件的分数坐标乘晶格得到的笛卡尔位置，曲面采用计算高度，共用Å坐标原点和xyz等比例缩放。p4vasp的周期展开高度保留原有分支，可能位于原晶胞之外。原子按crystalX的VESTA主题区分颜色与显示半径，半径随三维缩放变化。

## 目录与拖拽调节

打开文件的目录和最近成功载入的文件保存在项目目录 `.settings.ini`，下次启动自动载入该文件。二维与三维初始宽度约3∶1，可拖动中间分隔条修改。
恒流滑条采用对数刻度，范围根据数据密度确定。恒高滑条采用线性刻度，范围为所选表面到晶胞边界的可用高度。数值框允许精确输入，修改信号/高度后约250毫秒自动重算，计算期间的后续调节会在任务完成后处理。

## C++ 加速

`native/stm_native.cpp` 实现密度文本解析和 p4vasp 线性恒流搜索，通过 ctypes 调用。Windows 下使用 MinGW-w64 的 g++ 构建，无需 Python 开发头文件。

```sh
python build_native.py
```

构建生成 `stm_simulator/_stm_native.dll`，重启后自动启用。本地二进制和个人设置不提交到仓库，在其他机器拉取源码后需要运行构建脚本。缺少本地库时自动使用 NumPy 实现。恒高插值、限定真空算法和平滑采用原实现。

## 三维交互与颜色标尺

三维视图使用PyQtGraph OpenGL网格，由GPU完成旋转和投影。左图、三维曲面和色条共用同一线性颜色映射。默认铜色，可切换灰度或蓝绿。颜色设置位于右侧参数区下方。
恒流色标默认显示绝对高度z/Å，可切换为相对最低高度Δz/nm。恒高色标显示原始密度，三维平面z仍是实际截面高度。固定范围允许输入上下限，超范围值截为端点颜色。PNG导出包括色条、刻度和单位。

颜色范围设计参考[Gwyddion颜色映射说明](https://www.gwyddion.net/documentation/user-guide-en/color-map.html)，提供线性全范围和固定范围。实验软件允许选择配色与范围，需使用同一设置进行数值对照。
恒流调节采用对数滑条，因为真空中信号随距离近似指数衰减，同等比例信号变化通常对应更均匀的高度变化。色条采用线性映射。

## 原子种类与表面选择

PARCHG中的元素名称与原子计数会展开成每个原子的种类，显示颜色与半径采用本地crystalX项目的`config/default/VESTA.ovito-theme`。三维图顶部可分别勾选显示原子、原子种类标签，标签随视图投影在原子旁显示元素符号。旧式VASP4文件缺少元素行时使用X1、X2分组标签，未识别元素采用灰色和默认显示半径。

“扫描表面”选择当前slab的上侧或下侧，分别沿−c、+c搜索。限定真空算法可用z下界和上界限定所选侧的搜索区间。若需要(111)等特定晶面，应先构建该晶面的slab、添加真空并用VASP计算其PARCHG，再导入本程序。输入需要a、b在xy面内，正c轴沿z。

## 高度文件模式

先打开目标PARCHG，再点击“导入高度”，选择恒流模式导出的NPZ（values为二维Å高度、lattice为晶格、unit为Å）。晶格和面内网格需要匹配。程序在各点高度z(x,y)对目标密度沿z线性插值，周期处理展开高度，缺失高度保留NaN。二维图显示采样密度，三维图以导入高度为几何形状、采样密度为颜色。该模式可用于比较不同偏压下同一高度轨迹的信号。PNG不包含可恢复的逐点高度，请使用导出数据得到的NPZ。

## 浅色界面与原子光照

界面采用浅色主题。原子通过GPU球面着色显示明暗和高光，视空间距离增加时亮度与透明度轻微衰减，旋转时实时更新。透明原子按远到近排序，元素颜色和显示半径仍来自crystalX主题。
