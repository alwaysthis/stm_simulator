# UI 设计

参考 studio 分支 src/ui/theme/constants.py 与 src/ui/components/widgets.py。
深灰 chrome #242424、page #222222、card #1c1c1c、tab strip #303030、field #1e1e1e、edge #303030、accent #4a90d9。
控件和卡片圆角 4px、面板 8px、工作区标签顶部 10px。字体 13px，标签文字 12px。
标签宽为文字宽+16px（最小64px），另留4px间距，高度 max(26,font height+12)。选中填充与页面相同，标签文字位置和颜色保持稳定，悬停为完整圆角块。
下拉箭头为1.6px两段细线。菜单暗底、蓝色选择，禁用滚轮修改。
数值框使用 QDoubleSpinBox，禁用滚轮和即时提交，悬停/焦点蓝色边框。z边界允许留空自动。
页面内边距左右24px、上下10px。没有底部日志。
当前未移植参考应用的整套拖拽、关闭标签和页面凸形描边系统，STM仅有固定两页。

标签栏左上角外侧使用窗口底色 #242424，沿选中标签相同的10px曲线裁去灰底，避免第一个标签选中时出现灰色角块。

2026-11-09 用户确认取消工作区标签页，直接显示图像。顶部“帮助”按钮弹窗显示方法说明。此前标签页样式约定作为历史参考。

移除单模块 STM 左侧导航按钮，启动窗口为1240×720逻辑像素，最小尺寸950×650。

二维和三维图同页并排，分隔条可调整宽度。三维区域顶部有“显示原子”勾选，默认开启。导入进度在底部临时显示，计算时显示忙碌进度。

二维/三维初始宽度3∶1。三维标题和原子开关上下排列适应窄宽度。目标信号下方为对数滑条，高度下方为线性滑条，数值框同步并触发防抖自动预览。

三维改为GPU OpenGL，xyz共用等比例Å标尺，原子采用文件中的原始笛卡尔坐标。左图右侧色条显示数值和单位，颜色卡片提供铜色/灰度/蓝绿、全范围/固定范围、高度Å/相对最低高度nm选项。双图颜色映射统一。

三维标题下“显示原子”与“原子种类标签”独立勾选，标签默认关闭。元素配色和显示半径参考本地crystalX的VESTA.ovito-theme，标签投影到原子旁随视角移动。扫描表面下拉提示解释上下表面方向和指定晶面slab准备。
